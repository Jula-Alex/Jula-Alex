# Hi, I'm Alex

I'm a Junior Embedded Software Developer focused on C, C++ and microcontroller-based systems.

My professional background combines embedded software development in C on Arduino and STM32 platforms with previous technical training as an electrician and a qualification as a Fachinformatiker für Anwendungsentwicklung.

## Purpose of This GitHub

This GitHub documents my transition from embedded development in C toward modern embedded C++.

I started this personal learning path without previous C++ experience.

My objective is not to relearn embedded fundamentals such as GPIO, timers, PWM or communication protocols. Instead, I want to take the embedded concepts I already know and learn how to design and implement them using modern C++ and object-oriented software design.

A major goal of this process is to become capable of designing embedded software architectures and complete projects independently from scratch.

## Learning Approach

During the first phase of this journey, I use ChatGPT as a technical tutor.

Rather than generating complete projects for me, the purpose of this guidance is to help me understand C++ concepts, reason about design decisions and progressively implement the software myself.

This includes topics such as:

- classes and object-oriented design
- encapsulation and separation of responsibilities
- references and pointers
- const correctness
- object lifetime and ownership
- state management
- hardware abstraction
- interrupt-driven design
- non-blocking software
- reusable embedded components
- interfaces between application logic and hardware

As my understanding improves, the amount of guidance should gradually decrease.

The long-term objective is to reach the point where I can define the architecture, make implementation decisions, solve problems and develop complete embedded projects in C++ independently.

## Project Progression

My projects are separated into two stages.

### Guided Learning Projects

These projects are part of my C++ learning phase and are developed with ChatGPT acting as a technical tutor.

The implementation, testing and hardware validation are performed by me, while design decisions and unfamiliar C++ concepts will be discussed step by step.

These projects document the progression from my existing embedded C knowledge toward structured embedded C++ development.

### Independent Projects

Projects in this section are designed and implemented independently.

For these projects, I define the architecture, component responsibilities and implementation strategy myself.

ChatGPT may still be used for documentation, research or code review, but not as step-by-step guidance for designing the project.

This section represents the stage where the concepts practiced during the guided phase have become part of my own development process.
